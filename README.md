# movie_booking website
Movie Ticket Booking Website  A web-based Movie Ticket Booking System inspired by platforms like BookMyShow, developed using the Django Web Framework. The application provides users with a convenient platform to explore movies, view show timings, check available seats, and book movie tickets online.  Key Features  * User Authentication: User registration, login, and logout functionality. * Movie Listings: Browse available movies with details, descriptions, genres, and posters. * Show Management: View movie schedules, showtimes, and theatre information. * Seat Selection: Select preferred seats based on availability. * Ticket Booking: Book movie tickets through an interactive booking process. * Booking Management: View and manage booking details. * Admin Dashboard: Manage movies, theatres, show timings, and bookings. * Responsive UI: User-friendly interface for smooth navigation.  Technologies Used  * Backend: Python, Django * Frontend: HTML, CSS, JavaScript, Bootstrap * Database: SQLite / MySQL (depending on your configuration) * Tools: VS Code, Git, GitHub  Project Objective  The main objective of this project is to develop an online movie ticket booking platform that simplifies the ticket reservation process, improves user convenience, and provides efficient management of movies, theatres, schedules, and bookings.  Future Enhancements  * Online payment gateway integration. * Email and SMS booking confirmations. * QR-code-based ticket generation. * Movie ratings and reviews. * Advanced movie search and filtering.
